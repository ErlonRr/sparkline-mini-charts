## 🎯 Criteri Standard di Valutazione per Ogni Componente

Ogni singolo componente del progetto viene analizzato secondo una matrice di 8 pilastri qualitativi:

1. **Standard Vanilla JS 2026 & Modern Web APIs**:
   - Utilizzo di Custom Elements v1 e Shadow DOM (`mode: "open"`).
   - Campi e metodi privati nativi (`#privateField`, `#privateMethod`).
   - Gestione asincrona dei render via microtask (`queueMicrotask`) per evitare layout thrashing.
   - Totale assenza di dipendenze esterne a runtime e compatibilità SSR (guardie su `globalThis.HTMLElement`, `requestAnimationFrame`, `document`).
2. **Tipizzazione & Documentazione JSDoc**:
   - Header standard del file con descrizione chiara (1-2 righe).
   - JSDoc sintetico e completo (`@extends`, `@param`, `@returns`, `@typedef`).
   - Validazione tipi senza errori in `pnpm typecheck`.
3. **Input, Output & Reattività (API Surface)**:
   - Sincronizzazione bidirezionale tra attributi HTML (`data`, `label`, `min`, `max`, `zones`, ecc.) e proprietà JavaScript.
   - Parsing difensivo e resiliente su dataset non validi, vuoti (`[]`), singoli (`[10]`), valori negativi, `NaN`, `Infinity` o mismatch dimensionali.
   - Ottimizzazione del diffing DOM per minimizzare distruzioni/creazioni di nodi SVG.
4. **Animazioni, Motion Design & Gestione Risorse**:
   - Animazioni d'ingresso fluide (SVG mask wipe, `stroke-dashoffset`, `d` morphing).
   - Rispetto di `@media (prefers-reduced-motion: reduce)`.
   - **Prevenzione Memory Leak**: Cancellazione e cleanup puntuale di `setTimeout`, `requestAnimationFrame` ed eventuali listener DOM al momento della disconnessione (`disconnectedCallback`).
5. **Accessibilità (A11y & WCAG 2.2)**:
   - Ruoli semantici appropriati (`role="img"`, `role="meter"` per gauge/progress).
   - Attributi `aria-label`, `aria-valuemin`, `aria-valuemax`, `aria-valuenow`.
   - Tag `<title>` interno all'SVG sincronizzato con la label.
6. **Styling, CSS Custom Properties & `::part()`**:
   - Variabili CSS temabili con valori di fallback coerenti (`--mini-chart-color`, `--mini-chart-stroke-width`, `--mini-chart-bullish-color`, ecc.).
   - Esposizione consistente delle parti Shadow DOM tramite attributi `part="..."` per styling esterno via `::part()`.
   - Utilizzo di `aspect-ratio` nativo CSS scalabile.
7. **Disaccoppiamento Geometria & Algoritmi (`src/core/geometry.js`)**:
   - Calcolo matematico delle coordinate 100% puro e testato isolatamente.
   - Nessun calcolo computazionalmente pesante duplicato durante i cicli di render.
8. **Copertura Test (Vitest)**:
   - Test unitari sulla logica geometrica pura.
   - Test di integrazione/render sul Web Component (rendering vuoto, rendering con dati, aggiornamento attributi, fallback label).
