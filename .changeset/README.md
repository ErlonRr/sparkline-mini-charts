# Changesets

Every pull request that changes the published package adds a changeset here: `pnpm changeset`, pick the bump, then write the notes as [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) sections (`### Added`, `### Changed`, `### Deprecated`, `### Removed`, `### Fixed`, `### Security`) with user-facing bullets. See "Changesets" in [CONTRIBUTING.md](../CONTRIBUTING.md).
