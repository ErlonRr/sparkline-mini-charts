Installation

Install the package from npm and import the side-effect registration entry point once in your application.

npm install sparkline-mini-charts

App Entry Point (e.g. main.js / index.ts):

import 'sparkline-mini-charts/register';

Framework Integrations

Standard Web Components work in any environment. Use native Custom Elements directly or via first-class typed wrappers.

Import registration script once and use standard Custom Elements in your HTML.

<!-- Include registration bundle -->
<script type="module" src="https://cdn.jsdelivr.net/npm/sparkline-mini-charts/register"></script>

<!-- Use sparklines anywhere -->
<mini-line-chart 
  data="[18, 23, 20, 31, 27, 38, 44]" 
  curve="smooth" 
  trend-color="auto" 
  label="Weekly revenue trend"
></mini-line-chart>

First-class React components with full TypeScript prop typings.

import { MiniLineChart, MiniAreaChart } from 'sparkline-mini-charts/react';

export function MetricsWidget() {
  const weeklyData = [18, 23, 20, 31, 27, 38, 44];

  return (
    <div className="metric-card">
      <span>Revenue</span>
      <MiniLineChart 
        data={weeklyData} 
        curve="smooth" 
        trendColor="auto" 
        label="Revenue trend" 
      />
    </div>
  );
}

Typed Vue 3 Composition API components for SFC templates.

<script setup lang="ts">
import { MiniLineChart, MiniAreaChart } from 'sparkline-mini-charts/vue';

const revenueData = [18, 23, 20, 31, 27, 38, 44];
</script>

<template>
  <div class="metric-card">
    <MiniLineChart 
      :data="revenueData" 
      curve="smooth" 
      trend-color="auto" 
      label="Revenue trend" 
    />
  </div>
</template>

Angular directive supporting standalone components with `CUSTOM_ELEMENTS_SCHEMA`.

import { Component, CUSTOM_ELEMENTS_SCHEMA } from '@angular/core';
import 'sparkline-mini-charts/register';

@Component({
  selector: 'app-metric-card',
  standalone: true,
  schemas: [CUSTOM_ELEMENTS_SCHEMA],
  template: `
    <mini-line-chart 
      [attr.data]="data | json" 
      curve="smooth" 
      trend-color="auto" 
      label="Revenue trend">
    </mini-line-chart>
  `
})
export class MetricCardComponent {
  data = [18, 23, 20, 31, 27, 38, 44];
}
