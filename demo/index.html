Installation & Setup

Install the package via your preferred package manager and import the registration script once in your app's entry point.

npm install sparkline-mini-charts

Main Entry Point (e.g., main.js)

import 'sparkline-mini-charts/register';

Framework Integrations

Standard Web Components work anywhere. Select your framework to see the exact implementation pattern.

In standard HTML, pass the data as a JSON string attribute.

<mini-line-chart data="[18, 23, 20, 31, 27, 38, 44]" label="Weekly revenue trend"></mini-line-chart>

In React 19+, Custom Elements are natively supported. In older versions, pass complex data as a JSON string.

export default function App() {
  const chartData = JSON.stringify([18, 23, 20, 31, 27, 38, 44]);
  
  return (
    <mini-line-chart data={chartData} label="Weekly revenue trend"></mini-line-chart>
  );
}

In Vue, configure compilerOptions.isCustomElement in your Vite config, then pass data dynamically.

<script setup>
const data = JSON.stringify([18, 23, 20, 31, 27, 38, 44]);
</script>

<template>
  <mini-line-chart :data="data" label="Weekly revenue trend" />
</template>

In Angular, add CUSTOM_ELEMENTS_SCHEMA to your module/component and bind the attribute.

import { Component, CUSTOM_ELEMENTS_SCHEMA } from '@angular/core';
import 'sparkline-mini-charts/register';

@Component({
  selector: 'app-chart',
  standalone: true,
  schemas: [CUSTOM_ELEMENTS_SCHEMA],
  template: `
    <mini-line-chart [attr.data]="chartData | json" label="Weekly revenue trend"></mini-line-chart>
  `
})
export class ChartComponent {
  chartData = [18, 23, 20, 31, 27, 38, 44];
}
