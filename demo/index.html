The 4 Levels of Customization

1. One Brand Token (`--mini-chart-color`)

Single-series charts take their primary color from --mini-chart-color (default #2563eb), not from the inherited CSS color. Set it once on a container and every chart inside follows. 

.metric-card.success {
  --mini-chart-color: var(--brand-success);
}

2. CSS Custom Properties (`--mini-chart-*`)

Map your Design System tokens directly to our standardized CSS properties at the root or container level. 

:root {
  --mini-chart-color: var(--color-primary-500);
  --mini-chart-bullish-color: var(--color-emerald-500);
  --mini-chart-bearish-color: var(--color-rose-500);
}

3. Shadow Parts (`::part(...)`)

Target discrete SVG elements inside the Shadow DOM like ::part(line), ::part(point-last), or ::part(wick) for advanced design control. 

mini-line-chart::part(point-last) {
  fill: var(--color-accent);
  stroke: #ffffff;
  stroke-width: 2px;
}

4. Reduced Motion

Charts follow the user's prefers-reduced-motion setting on their own: entrance and update transitions become instant, and the plotted values stay exactly the same. There are no motion tokens to set. 

/* Nothing to add: inside every chart's shadow root */
@media (prefers-reduced-motion: reduce) {
  /* transitions and animations run in ~0 ms */
}

Framework Integrations

Standard Web Components work in any environment. Use native Custom Elements directly or via first-class typed wrappers.

Import the registration script once and use standard Custom Elements in your HTML. 

<!-- Include registration bundle -->
<script type="module" src="https://cdn.jsdelivr.net/npm/sparkline-mini-charts@1/dist/register.js"></script>

<!-- Use sparklines anywhere -->
<mini-line-chart 
  data="[18, 23, 20, 31, 27, 38, 44]" 
  curve="smooth" 
  trend-color="auto" 
  label="Weekly revenue trend"
></mini-line-chart>

First-class React components with full TypeScript prop typings and event listeners. 

import { MiniLineChart, MiniGaugeChart } from 'sparkline-mini-charts/react';

export function MetricsWidget() {
  const weeklyData = [18, 23, 20, 31, 27, 38, 44];

  return (
    <div className="metric-card">
      <span>Revenue Trend</span>
      <MiniLineChart
        data={weeklyData}
        curve="smooth"
        trendColor="auto"
        interactive
        onSparklineHover={(e) => console.log('Hovered point', e.detail)}
        label="Revenue trend"
      />

      {/* Gauge with Continuous Multi-Stop Gradient */}
      <MiniGaugeChart
        data={[72, 0, 100]}
        gradient={['#10b981', '#f59e0b', '#ef4444']}
        interactive
      />
    </div>
  );
}

AOT-safe recipe: register the elements once, allow custom elements with CUSTOM_ELEMENTS_SCHEMA, and bind [data] as a property on the raw tags. Events are plain DOM events, bound by their kebab-case name. 

import 'sparkline-mini-charts/register';
import { CUSTOM_ELEMENTS_SCHEMA, Component, signal } from '@angular/core';

@Component({
  selector: 'app-metric-card',
  schemas: [CUSTOM_ELEMENTS_SCHEMA],
  template: `
    <mini-line-chart
      [data]="data()"
      curve="smooth"
      trend-color="auto"
      interactive
      (sparkline-hover)="onHover($event)"
      label="Revenue trend">
    </mini-line-chart>

    <!-- Gauge with a multi-stop gradient and zone-change events -->
    <mini-gauge-chart
      [data]="gaugeValue()"
      [attr.gradient]="gaugeGradient"
      interactive
      (zone-change)="onZoneChange($event)">
    </mini-gauge-chart>
  `
})
export class MetricCardComponent {
  readonly data = signal([18, 23, 20, 31, 27, 38, 44]);
  readonly gaugeValue = signal([75, 0, 100]);
  // Attribute options take JSON text.
  readonly gaugeGradient = '["#10b981", "#f59e0b", "#ef4444"]';

  onHover(event: Event) {
    console.log('Hover point:', (event as CustomEvent).detail);
  }

  onZoneChange(event: Event) {
    console.log('Zone changed:', (event as CustomEvent).detail);
  }
}
